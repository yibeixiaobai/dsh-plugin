【极简确定性两阶段闭环执行时序】
1. **阶段零（预检与规范自省）**：
   - 调用 `social_publisher(action: "detect_login", account_id: acc.id)` 探测目标账号健康度；
   - 调用 `social_publisher(action: "get_content_rules", account_id: acc.id)` 获取排版规范与篇数配额；
2. **阶段一（选题策划与批量全自动物料闭环）**：
   - 查重锁定最优选题后，大模型根据账号所需篇数（如 3 篇或 6 篇长文，若有小绿书同步产出小绿书卡片），一次性撰写全量深度正文草案；
   - 一次性调用统一生产工具：
     `social_publisher(action: "produce", account_id: acc.id, articles: [{ title: "...", content: "..." }, ...])`；
   - **底层全自动物料闭环**：底层管线全自动完成「沙箱分配 -> 微信单行零换行富文本 HTML 编译 -> 封面（头条 2.35:1 / 次条 1:1）与正文插图（16:9）尺寸自适应匹配 -> AI 绘图与网络搜图打散去重混排 -> 遇到网络异常秒级降级保底 -> 机器合规校验 -> Manifest 签名」，无需大模型多轮往返！
3. **阶段二（高保真审校与强制人机确认门禁）**：
   - 物料生成完毕后，中央画布会自动展开高保真预览；
   - **Agent 必须立即终止调用发布工具，结束当前回复！严禁在同一回复内擅自调用发布！**
   - 在对话中呈现精简审校卡片，提示用户：「全部图文与配图已生成完毕并通过合规校验！您可在中央画纸中审校图文效果；确认无误后点击下方按钮【推送到官方草稿箱】或在对话中发出确认指令，我才会为您推送到官方平台。」
4. **阶段三（终局发布与排期执行）**：
   - 收到用户的明确发布确认指令后（携带 `user_confirmed: true`），调用统一发布入口：
     `social_publisher(action: "publish", account_id: acc.id, task_id: "...", user_confirmed: true)`；
   - **发布动作自适应决议**：底层严格遵循账号默认配置（若账号配置为 `schedule` 定时发布，自动避让已占用槽位提交微信后台原生定时发表；若为 `draft` 则存入草稿箱）；若用户在确认指令中指定具体动作或时段，自动最高优先级覆盖；
   - **多图文合辑与小绿书双发**：多篇长文自动组合为单一多图文合辑草稿原子提交；若账号配置了小绿书双发，底层自动紧接着完成小绿书独立发布；
   - 发布完成后调用 `gzh_verify_draft` 回查核验，沙箱原子归档。
5. **阶段四（全量成果汇总报告）**：
   - 统一以 Markdown 表格输出本次任务的汇总对照表：【账号名称】、【发布平台】、【文章标题】、【字数】、【配图张数】、【草稿 MediaID / 排期时间】。
