执行百家号（`baijiahao`）社媒自动化内容生产与发布工作流。

用户输入参数：`$ARGUMENTS`

【输入参数解析与目标账号锁定规则】
1. **单账号限定模式**：若输入参数首词为具体账号名称或账号 ID，严格仅在该指定账号下推进流水线，后续文字全部作为选题与补充要求；
2. **缺省多账号全量巡航模式（默认行为）**：若用户未指定特定账号（参数为空，或整句均为选题/创作要求），**默认必须调度百家号平台下【所有已启用账号】（`platform === 'baijiahao' && enabled === true`）！严禁仅执行第 1 个账号就早退！**

【业务任务角色与免检声明】
当前任务为面向社交媒体平台的端到端内容生产与发布业务，非软件开发/代码修改任务！严禁执行 check-workspace-freshness.mjs、Git 状态检查或任何代码仓库维护命令，直接开始内容生产流水线。

【执行纪律与防迷航铁律】
1. **工具可用性与零终端嗅探**：当前环境已通过 MCP Stdio 连接专用社媒工具集，所有配置、账号与流水线必须且只能通过 MCP 工具推进。系统已全面支持短名称（推荐直接调用 `gzh_get_style_guide`、`gzh_check_topics`、`gzh_build_article`、`gzh_generate_images`、`gzh_validate_html`、`gzh_publish_draft`、`gzh_verify_draft` 等）及命名空间全名称（系统已做连字符 `-` 与下划线 `_` 双向别名容错，均可正常执行）！仅在会话初始工具清单中完全没有任何社媒工具时才输出错误：“社媒发布插件 MCP 服务未就绪，请在设置中检查插件状态或新建会话”。在任务执行过程中严禁自行中断或将参数差异误判为服务掉线！严禁在系统终端编写脚本或尝试自启动服务！严禁在终端执行 ping/sleep 睡眠循环等待重试！严禁在终端运行 grep/find/cat/python 检索配置文件（如 gzh.config.json），严禁调用外部全局 gzh CLI。
2. **独立全新任务与严禁检查本地已有产物（绝对铁律）**：当前任务为一个完全独立的全新任务！每次执行插件任务都是全新立项，严禁在任务启动时或执行过程中通过任何命令（`dir` / `ls` / `find`）或工具（`view_file`）扫描、检查、查看本地是否已存在历史产物或旧文件夹内容！严禁试图查找、复用或询问用户是否复用旧文件！所有产物路径文件夹均由底层工具按规则自动创建并写入，Agent 必须端到端全流程推进全新创作。历史已发布选题的唯一合法排重依据是专用 MCP 工具（调用 `gzh_check_topics` 比对持久化历史库，或查阅 `gzh_get_style_guide` 返回的 `recent_titles`），严禁向历史对话或本地文件求证！
3. **空参自主闭环**：若用户未指定选题，围绕账号领域调用网络搜索与 `gzh_discover_topics(platform: "baijiahao")` 自动探测热门爆款切角，调用 `gzh_check_topics` 查重，自主确定优质选题。
4. **【严禁单账号早退铁律】**：当本次任务需要处理多个账号时，必须针对目标账号列表中的【每一个账号】独立推进完整的生命周期流水线！严禁只生成并发布一个账号便提前终止！必须完成全部目标账号的发布后再输出最终成果。
5. **【账号配置严格遵从与严禁自由发挥铁律（系统绝对红线）】**：各账号任务执行全生命周期（发文形态、计划篇数、正文最低字数、配图分配模式、生图与搜图数量、核心业务关键词、偏好选题切入角度、红线禁用词、品牌引导等），必须 100% 严格按照设置页为该账号配置的信息执行（以 gzh_get_style_guide 返回的结构化配置为唯一准则）！严禁 Agent 凭空臆造、主观自由发挥、私自增减篇数（严禁知乎/百家号/头条擅自脑补多篇，公众号严格按配额执行）、偷工减料降低字数（设置 2500 字绝不可写 800 字）、脱离核心业务关键词或触碰红线词！仅当用户在当前指令中明确发出覆盖参数（如“本次只要1篇”或“本次不要插图”）时，才允许覆盖该单个参数，其余未被明确覆盖的设置项依然必须严格遵从设置页！

【标准化多账号执行时序】
1. **账号自省与目标池锁定**：
   - 第一步调用 `gzh_get_style_guide(platform: "baijiahao")`；
   - 检查返回结果中的 `platform_accounts`（或从 `available_accounts` 中提取 `platform === 'baijiahao' && enabled === true` 的账号列表）；
   - 若用户输入指定了特定账号，锁定该账号为唯一目标 `target_accounts = [指定的账号]`；
   - 若用户未指定特定账号，锁定全部已启用的百家号账号为待执行目标池 `target_accounts = platform_accounts`。
2. **循环遍历执行流水线**：
   - 针对 `target_accounts` 中的每一个账号 `acc`，按顺序独立执行其专属流水线：
     - **步骤 A（规范获取）**：调用 `gzh_get_style_guide(account_id: acc.id)` 获取百家号排版规范（Markdown 长文、2.35:1 封面配图、首尾品牌图）；
     - **步骤 B（选题查重与全自动定题）**：结合用户要求与账号领域，调用 `gzh_check_topics(account_id: acc.id, ...)` 针对该账号历史标题查重；查重后根据 0% 安全度与爆款热度指数自动锁定最优选题，立即无缝推进至步骤 C，严禁中途停顿等待确认（除非用户明确备注要求指定选题或要求手动挑选）；
     - **步骤 C（文章构建）**：根据规范撰写文章，调用 `gzh_build_article(account_id: acc.id, ...)` 构建 Markdown 文章；
     - **步骤 D（AI 生图与网络搜图协同配图）**：调用 `gzh_generate_images(account_id: acc.id, ...)` 生成封面与正文插图（正文插图设计默认采用 16:9 宽屏科技信息图表/全流程看板，严禁空讲台、叠放书本眼镜钢笔等装饰性静物摆拍）；
     - **步骤 E（合规校验）**：调用 `gzh_validate_html(account_id: acc.id, ...)` 机器合规硬性校验；
     - **步骤 F（草稿发布）**：调用 `gzh_publish_draft(account_id: acc.id, ...)` 通过浏览器自动化保存至百家号草稿箱，并调用 `gzh_verify_draft(account_id: acc.id)` 回查核验。
3. **全量成果汇总报告**：
   - 全部账号执行完毕后，统一以 Markdown 表格输出本次任务的汇总对照表，包含：【账号名称】、【账号 ID】、【文章标题】、【字数】、【配图张数】、【草稿箱状态】。
